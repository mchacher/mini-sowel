# Architecture: Spec 022

## Overview

```
 crates/core (hardware-free, tested on the Mac)            used by
 ├─ network.rs   WifiSettings, wifi_settings, WifiRefusal     spec 023's firmware (boot, console)
 │               boot_lines_radio, Backoff, wifi_reason,
 │               retry_line, connected_line,
 │               parse_console_line → ConsoleCommand
 ├─ api/mod.rs   Request.reach: Loopback | Lan { name }       host (Loopback), spec 023 (Lan)
 │               host_allowed(.., reach); pairing 404 on Lan
 ├─ api/slots.rs Slots (4), SlotGuard          ◀── moved ──── host serve.rs busy counter
 ├─ api/static_files.rs STATIC_HEADERS,        ◀── moved ──── host static_files.rs
 │               cache_control, find(table, path)
 ├─ live/session.rs origin_allowed, subprotocol, ◀── moved ── host ws.rs
 │               TICK_MS, PING_SECONDS, ...
 └─ memory.rs    heap_line(.., http stack)                     spec 023's firmware

 crates/ui-embed (new)  ui/dist ─ collect ─ gzip -9 ─ generate ─▶ OUT_DIR/ui_files.rs + *.gz
                                                                  (spec 023's firmware/build.rs)
 scripts/  demo-garage.sh <port | address[:port]>   measure-api.sh <address> (33 requests)
           box.sh flash --keep-storage, ownership line;  box.sh wifi [--forget] ─▶ serial console
```

The host is changed only where it hands logic to the core (the origin rule, the constants, the
static headers, the slots), with its behaviour unchanged: its existing tests pass unchanged before
anything new is added. No firmware file changes; the four images build as before.

## Reused

- `network::parse` / `choose` (`crates/core/src/network.rs:58-98`) for `boot_lines_radio`.
- `solite_core::api::static_files::route` and `content_type` (`static_files.rs:42`): `ui-embed`'s name
  check mirrors the route's.
- The host's `busy` counter (`serve.rs:220-247`), `ws.rs`'s origin rule and constants, and
  `static_files.rs`'s headers, moved as they are.
- `box.sh`'s port lookup, `/dev/tty` prompt pattern (`confirm`), Python capture with DTR/RTS low so
  the port opens without a reset (`capture`), `--dry-run`, `fw_*` helpers; its test harness with a
  pseudo-terminal and fakes (`crates/host/tests/box_script.rs:122-370`).
- `demo-garage.sh`'s checks and its test host (`crates/host/tests/demo_script.rs:48-110`) for
  `measure-api.sh`'s tests.

## Risks

- A move that changes the host's behaviour on the quiet: the host's existing tests (`ws.rs`,
  `serve.rs`, `static_files.rs`) run unchanged right after the moves (plan step 2), before anything
  new is added.
- `box.sh wifi` has no counterpart on the box until spec 023: its tests fake the console; on a real
  box today it answers exit 4, which the living spec states.
- A gzip that differs between two builds would change the firmware image for nothing: the header
  carries no time, and a test checks two runs give the same bytes.
